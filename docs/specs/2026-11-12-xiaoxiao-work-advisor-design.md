# 小小 v0.3.0：工作顧問（顧問模式）設計

日期：2026-11-12。屬於 v0.3.0「對話更順」，是這一版的主項；插話打斷、追問帶上下文另外設計。

## 1. 意圖

使用者想用語音跟小小討論工作上的事，像跟同事邊想邊聊，由小小提供想法與建議。現在的一般問答只等 8 秒、最多 3 輪，每輪都要先叫「小小」，回答也限一兩句，發想時很容易被切斷。顧問模式要做的就是讓一段討論能連續進行下去，討論完把重點留下來。

## 2. 目標／非目標／反目標

**目標**
- 用一句話進入顧問模式，之後不限輪數、不用叫名字，連續討論。
- 小小記得這段討論前面說過的內容，給的建議有實質內容。
- 結束時唸出摘要，使用者確認後才存成筆記。

**非目標（這一版不做）**
- 讀程式碼、文件、待辦、行事曆、信件等工作資料。這一版只靠對話本身討論（使用者決定：「自由發想、不先讀資料」）。之後再加使用者勾選開放的 skill／MCP，公開 repo 不寫死任何公司 MCP。
- 顧問模式中做事（設提醒、計時、記筆記）。
- 插話打斷（另一項）。
- 存逐字稿。功能清單的「不做對話紀錄」照舊；這裡只存使用者確認過的摘要。

**反目標（功能做出來，碰到這些也算失敗）**
- 旁人講話或環境雜音讓小小在沒人問的情況下長篇大論。
- 沒經過確認就寫筆記。
- 一般問答變慢，或一般問答的追問規則被改掉（仍然是 8 秒、3 輪、要叫名字）。
- 提示詞外漏（唸出「這是發想類」之類的判斷過程）或唸出條列符號。

## 3. 使用者決定

| 項目 | 決定 |
|---|---|
| 第一版範圍 | 自由發想，不先讀資料 |
| 進入／結束 | 說「我們來討論」進入；說「先這樣」或沉默太久就結束 |
| 等待與輪數 | 顧問模式每輪約等 20 秒、不限輪數；一般問答維持 8 秒、3 輪 |
| 叫名字 | 顧問模式中不用叫「小小」 |
| 存檔 | 結束時唸摘要、問要不要存重點，說「對」才寫進本機 Markdown 筆記 |
| 模型 | 顧問模式用 sonnet，設定檔可改；一般問答維持 haiku |
| 回答長度 | 每次三到五句口語，結尾反問一句把討論推下去 |
| 旁人誤收 | sonnet 判斷不是對小小說的話就不回應，連續 3 次就結束顧問模式並問存檔 |
| 講完判斷 | 顧問模式停頓 1.5 秒才算講完、一句最長 30 秒；一般問答維持 0.8 秒、10 秒 |

## 4. 互動流程

```
待命 ──喚醒詞／快捷鍵──▶ 聽問題 ──「我們來討論」──▶ 小小：「好，你說」
                                                    │
                ┌───────────────────────────────────┘
                ▼
          顧問窗口（約 20 秒、不用叫名字）
           │ 開口：送 sonnet → 唸三到五句 → 回到顧問窗口
           │ 說「先這樣」 ─────────────┐
           │ 沉默約 20 秒 ─────────────┤
           ▼                            ▼
                               唸摘要＋「要存重點嗎」
                               ├ 對／好 → 寫筆記 →「存好了」→ 待命
                               ├ 不用／算了 →「好」→ 待命
                               └ 約 8 秒沒回答 → 不存 → 待命
```

1. **進入**：叫醒後聽到的那句符合進入說法就進顧問模式，用本機規則判斷、不花 token。說法至少包括「我們來討論」「陪我想一下」「跟你討論一下」（完整清單由 builder 定，要有測試）。進入的那句若後面還接著內容（例如「我們來討論一下新功能怎麼排」），後半句直接當第一輪送出。
2. **每一輪**：窗口內開口就收音。顧問模式停頓 1.5 秒才算講完，一句最長 30 秒；一般問答維持 0.8 秒、10 秒（使用者決定）。轉文字後整句送 sonnet，不用 `strip_call_name` 過濾。回答一邊串流一邊唸，跟快答一樣按句子切。
   - **旁人誤收**（使用者決定）：sonnet 判斷這句明顯不是對小小說的（旁人對話、電視、自言自語），整個回覆只輸出一個不唸的標記（例如 `<<SKIP>>`），小小不出聲，直接重開顧問窗口。連續 3 次就結束顧問模式，照第 4 步問要不要存。中間只要有一次正常回應，計數就歸零。
3. **結束**：說法至少包括「先這樣」「好了」「今天到這」「結束討論」，用本機規則判斷。整句只有結束說法才算，「好了，那下一個問題是…」不算結束。
4. **摘要與存檔**：結束時請同一個 sonnet 程序產生兩份內容：唸的版本一兩句，存的版本是條列重點加一行主題。唸完問「要存重點嗎」，開一個一般長度（8 秒）的確認窗口。
   - **回答判斷**（我的決定，builder check 後補）：用本機規則判斷，不花 token，也不經過既有 haiku 確認程序。「對／好／存／可以」就存；「不用／算了／不要」就不存。其他回答（例如「等等，再補一點」）回到顧問模式，當成下一輪送出。三個字以內聽不懂的短回答（實機 11-13：「不用」被聽成「無用」）先再問一次「要存嗎？說對或不用」，第二次仍聽不懂就不存（使用者決定）。8 秒沒回答就不存。同意與拒絕的說法清單要有測試。
5. **沉默結束**：顧問窗口約 20 秒都沒人說話，就照第 4 步問一次要不要存。8 秒內沒回答就不存，直接回待命。（我的決定：不問就丟掉太可惜，一直等又會卡住。）
6. **討論中的特殊句子**：
   - 想做事（「提醒我…」）：這一版不在顧問模式裡做。sonnet 的提示詞要它回一句「討論完再叫我設定」，然後繼續討論。（我的決定：避免兩套確認流程交錯。）
   - 「休息」「現在幾點」這類本機指令：顧問模式中不攔，交給 sonnet。每則訊息照快答的做法加上當下時間。（我的決定：攔下來會打斷討論的節奏。）
   - 查網路：這一版不開工具。sonnet 回答時要說明那是它自己的判斷、沒有查過。

## 5. 引擎與程式結構

- `Endpointer` 的停頓與最長秒數改成可依模式注入，一般問答的預設值不變，要有回歸測試。
- 新增狀態 `Advising`，跟 `FollowUp`／`Confirming` 共用窗口機制（`open_window`），但用自己的窗口長度、不計入 `MAX_FOLLOWUP_WINDOWS`、不檢查名字。窗口長度寫成 `Timing` 欄位（預設約 20 秒），測試可以注入短值。
- 存檔確認可以沿用 `Confirming` 加既有的確認解析，也可以另開狀態，由 builder 決定；8 秒沒回答就不存。
- 顧問用獨立的 `Session`（模型讀設定、預設 `sonnet`、不給工具），系統提示詞放在 `prompts.rs` 新增的 `advisor_prompt()`：
  - 口語繁中、三到五句、不用條列／符號／markdown、不說出判斷過程。
  - 給一個具體想法或建議，結尾反問一句。
  - 不知道使用者的工作資料，需要時直接問，不假裝知道。
  - 被要求做事時回「討論完再叫我設定」。
  - 明顯不是對小小說的話，只輸出 `<<SKIP>>`。
- 一般快答的 haiku 常駐程序不受影響。顧問 `Session` 在進入時建立，結束時丟掉，不帶到下一次討論。
- **筆記**：沿用既有的 `notes_path`（預設「文件」資料夾的 `小小筆記.md`）和 `append_note`，標題用「日期 時間 主題」。（我的決定：用同一份筆記檔，使用者找得到。）
- **設定檔**：新增顧問模型欄位（例如 `advisor_model`，預設 `sonnet`），沒有這個欄位的舊設定檔要能正常讀取。
- **桌面小角色**：顧問模式要讓人看得出來（例如換一個表情或姿勢），細節由 builder 決定，沿用既有角色資產，不新增造型。

## 6. 失敗與暫停

- **sonnet 出錯或逾時**：照快答既有的失敗處理唸提示，留在顧問模式。逾時值由 builder 定，要比快答寬。
- **討論內容不因出錯消失**（我的決定，builder check 後補）：`Session::ask` 失敗會丟掉程序，所以本次討論的文字（使用者說的與小小回的）另外留在記憶體。程序重開時把這份文字重送給新程序，摘要才能涵蓋全程。顧問模式結束就丟掉，不落檔，不算逐字稿。
- **連續兩輪失敗**：結束顧問模式。前面有談過內容就照常問要不要存（摘要失敗時唸「存不了，先這樣」）；一輪都沒談成就不問。
- **進入暫停（通話、鎖定、休息）**：顧問模式直接結束，不問存檔，程序丟掉。（我的決定：通話中不能出聲，事後再問會讓人摸不著頭緒。）
- **斷網**：沿用 ecfb7f2 的 8 秒「查太久了」行為。

## 7. 隱私

跟一般問答一樣：只送轉出來的文字，不送聲音。紀錄檔只記事件（進入、每輪延遲、結束原因、有沒有存），不記內容；診斷模式例外，照既有規則。

## 8. 驗收

- **自動測試**（`cargo test --workspace`，用 fake claude）：
  - 進入說法會進顧問模式，後半句會當成第一輪。
  - 顧問窗口內不叫名字也會送出。
  - 窗口長度用注入的值、不受 3 輪限制。
  - 結束說法會觸發摘要；確認後筆記檔多一段，拒絕或逾時則筆記檔不變；其他回答會回到顧問模式。
  - 連續 3 次 `<<SKIP>>` 會結束顧問模式，中間有正常回應就歸零。
  - 程序失敗重開後，新程序收到先前的討論文字。
  - 顧問模式中 12 秒的話不會被切；一般問答仍是 10 秒上限。
  - 暫停會結束顧問模式。
  - 一般追問規則不變（既有測試全過）。
- **實機**（Mac，先用喇叭播 `say -v Meijia` 加快捷鍵叫醒自測，再請使用者實測）：進入、連續 5 輪以上（含一輪超過 10 秒的話）、結束存檔、沉默結束、背景有人說話（例如喇叭另外播一段對話）；每輪記錄延遲。Windows 由使用者另找時間測。
- **手冊**：`docs/manual.md` 補顧問模式說明，`docs/feature-checklist.md` 更新狀態。

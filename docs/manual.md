# 小小操作手冊

還沒裝的話，先看[安裝說明](install.md)。這份手冊講裝好之後怎麼用。

Mac 和 Windows 操作相同，有差別的地方會標出來。Windows 版還在準備發佈，實際行為可能還會調整。

## 叫小小的方法

小小醒著時，下面哪一種都可以。休息中只有快捷鍵和點擊有效，而且只會叫醒它，見[暫停和休息](#暫停和休息)。

| 方法 | 怎麼做 | 說明 |
|---|---|---|
| 喚醒詞 | 用平常的音量說「嘿，小小」 | 聽到叮一聲和「我在」，再說問題 |
| 快捷鍵 | Mac：Control+Option+Space<br>Windows：Control+Alt+Space | 可以在設定裡改 |
| 點小角色 | 用左鍵點桌面上的小角色 | 第一次打開時在螢幕右下角，可以拖到別的地方 |
| 點圖示 | 用左鍵點小小的圖示 | Mac 在螢幕右上角的選單列；Windows 在右下角的系統匣，可能收在「^」裡 |

## 桌面小角色

設定完成後，打開小小只會出現一個小角色，不會開視窗。開機不會自動啟動，要自己打開。

| 看到 | 意思 |
|---|---|
| 平常的表情，偶爾眨眼 | 待命中 |
| 眼睛睜大、旁邊有聲波 | 在聽 |
| 眼睛往上看、右上角有三個點 | 在想、正在載入，或討論中等你說話 |
| 嘴巴在動、旁邊有音量條 | 在說話 |
| 閉著眼睛、有 z | 休息或暫停中 |
| 右下角紅色驚嘆號 | 有問題，把滑鼠移上去看原因 |

- **拖曳**：按住移動，下次打開會在同一個地方。
- **右鍵**：休息／叫醒、設定、隱藏、結束小小。
- **隱藏**：角色收起來，小小繼續運作。從圖示選單按「顯示小角色」，或再打開一次小小，就會回來。
- **通話或開會**：角色會自動收起來，結束後回來。只分享螢幕、沒開麥克風時偵測不到，要自己隱藏。
- **換造型**：到設定的「小角色造型」打開抽屜，有小訊、小麥、小圓、小鴞、小雲、小喵、小芽、小企八個，選了馬上換。

對著圖示按右鍵也有選單，可以休息、顯示或隱藏小角色、開設定、結束小小。

## 說話的節奏

- 聽到「我在」後開始說，停頓約 0.8 秒就算說完，一次最長 10 秒。
- 6 秒內沒開口，小小會當作不用了。
- 顧問模式中（見[跟小小討論工作](#跟小小討論工作顧問模式)）停頓約 1.5 秒才算說完，一次最長 30 秒；小小回完後 20 秒內直接說就好，不用叫名字，也沒有輪數限制。
- 小小回答完的 8 秒內可以追問，開頭叫一聲「小小」就好（例如「小小，那兩公斤呢」），最多連續追問 3 輪。沒叫名字的話不會回應，避免把周圍的聲音當成問題。確認要做的事時，回「對」「取消」不用叫名字。
- 閒置 5 分鐘後會開新對話，之前聊的內容就接不上了。

## 可以請小小做什麼

### 固定指令

這些在你的電腦上直接處理，不經過 Claude，也不用連網。

| 想做的事 | 可以這樣說 |
|---|---|
| 問時間 | 現在幾點 |
| 問日期 | 今天幾號、今天星期幾 |
| 開始計時 | 計時十分鐘、計時半小時、幫我設一個五分鐘的計時 |
| 取消計時 | 取消計時 |
| 請小小休息 | 小小，先休息、小小你可以休息了、去休息吧 |

固定指令要整句符合才算。句子裡還有別的需求時，會交給 Claude 回答。

### 問天氣

例如「今天天氣如何」「明天高雄天氣如何」。台灣縣市大約一秒就有答案，資料來自 [Open-Meteo](https://open-meteo.com/)（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)），不花 Claude 額度。沒講地點時查設定裡的所在地。

國外城市、沒設定所在地、或連不上 Open-Meteo 時，會改用查資料的方式，比較慢，也可能查不到。

### 問問題、聊天

其他問題都交給 Claude，例如「一公斤幾公克」。簡單的問題會直接回答。

需要查資料時，小小會先說「我查一下」，超過 45 秒還沒查到就會停下來告訴你。預設只會查網路；要讓它讀你的檔案，得先把資料夾加進設定（見[設定](#設定)）。

### 跟小小討論工作（顧問模式）

想把一件事想清楚時，可以請小小當討論對象，不用每句都叫名字。

- 進入：說「我們來討論」「陪我想一下」或「跟你討論一下」，後面可以直接接內容，例如「我們來討論一下新功能怎麼排」。
- 小小每次用三到五句回答，並反問你一個問題，讓討論繼續。
- 結束：整句只說「先這樣」「好了」「今天到這」或「結束討論」；或是 20 秒沒說話，也會結束。
- 結束時小小會唸一段摘要，然後問「要存重點嗎」。說「對」「好」「存」「可以」才會存；說「不用」「算了」「不要」就不存；聽不清楚的短回答會再問一次「要存嗎？說對或不用」，第二次還聽不清楚就不存；說一整句別的話（例如「等等，再補一點」）會當作繼續討論；8 秒沒回答也不存。
- 要存的話，重點會寫在同一個筆記檔，標題是日期時間加主題。
- 旁人說話（例如電視）小小不會回應；連續 3 次就結束討論。
- 討論中不能設提醒或計時，小小會說「討論完再叫我設定」，也不會查網路。
- 顧問模式用 sonnet，回答比一般問答慢，也比較花額度；模型可以在設定檔的 `advisor_model` 改。
- 通話、鎖定或休息時，討論會直接結束，不唸摘要也不存。

### 幫你記事

| 動作 | 例子 | 要講清楚的事 |
|---|---|---|
| 提醒 | 提醒我三點開會 | 時間、內容 |
| 計時 | 幫我倒數二十分鐘 | 長度 |
| 筆記 | 記一下要回客戶的信 | 內容 |

小小會先複述一次，等你確認才動手：

- 說「對」「好」「可以」：照做，完成後會告訴你。
- 說「不對，改成……」：修正後再複述一次。
- 說「取消」「算了」：放棄。

確認時的 8 秒內直接回答就好，不用再喊喚醒詞。

**提醒和計時要注意：**

- 沒講上下午時，小小會取接下來最近、落在早上 7 點到晚上 10 點之間的時間，複述時會講完整，例如「今天下午三點」，聽到不對就更正。
- 重複提醒還不支援，說「每天」只會設一次，小小也會告訴你。
- 提醒會存起來，關掉小小也不會不見；時間過了才打開的話，會通知你錯過了哪個提醒。
- **計時不會存起來**，結束小小後就沒了。

筆記會加到一個 Markdown 檔的最後面，預設是「文件」資料夾的 `小小筆記.md`。

## 暫停和休息

| 情況 | 小小會怎樣 | 怎麼恢復 |
|---|---|---|
| 其他程式在用麥克風（通話、線上會議、錄音） | 自動暫停，放開麥克風 | 對方結束後約 2 秒內自動恢復 |
| 螢幕鎖定 | 自動暫停 | 解鎖後自動恢復 |
| 說「小小，先休息」，或在選單按「休息」 | 關掉麥克風，不聽也不回答；計時照響 | 點小角色、按快捷鍵、點圖示，或在選單按「叫醒」 |
| 待命 2 分鐘沒有互動 | 自動休息，和上一列相同；不會出聲，小角色閉上眼睛 | 同上 |

休息時發生的事：

1. 喊「嘿，小小」不會有反應，因為麥克風關著。
2. 點一下小角色或按快捷鍵，小小播起床音、張開眼睛，然後直接開始聽，不用喊喚醒詞，這時說問題就會回答。
3. 沒講話就回到待命，之後喊「嘿，小小」也會回答。閒置 2 分鐘，又會休息。

通話或鎖定時叫醒，要等暫停結束、麥克風打開才會播起床音，而且只回到待命，不會直接開始聽。通話和鎖定的時間不算閒置。

醒著時點一下或按快捷鍵不一樣：小小會說「我在」並直接開始聽，不用喊喚醒詞。

休息不會自己結束，但重開小小後會回到待命。

## 圖示選單的狀態

對著圖示按右鍵，選單最上面會顯示目前的狀態：

| 顯示 | 意思 | 要做什麼 |
|---|---|---|
| 待命中：說「嘿，小小」 | 正常 | 不用做什麼 |
| 在聽…／想一下…／說話中 | 正在處理你的問題 | 不用做什麼 |
| 可以直接追問 | 正在等你接著說 | 說「小小，……」，或不理它 |
| 討論中：直接說，說「先這樣」結束 | 正在顧問模式 | 直接說，或說「先這樣」結束 |
| 等你確認 | 正在等你回答對不對 | 說「對」或「取消」 |
| 暫停中 | 見上面的暫停和休息 | 依情況恢復 |
| 找不到可用的麥克風 | 沒有能用的輸入裝置 | 接上麥克風，或到設定改選 |
| 連不上 Claude：只能報時和計時 | Claude Code 不見了或沒登入 | 按選單裡的「去登入 Claude」 |
| 還沒完成設定：點「設定…」 | 引導還沒走完 | 開設定，走完引導 |
| 下載模型中…／載入中… | 正在準備語音模型 | 等它完成 |
| 模型下載失敗、無法啟動 | 後面會附原因 | 依原因處理，再重開小小；中斷的下載會接著補齊 |

## 設定

對小角色或圖示按右鍵，選「設定…」。按「儲存」後，小小會重新啟動才生效；小角色造型例外，選了馬上生效，不用儲存。

| 項目 | 說明 |
|---|---|
| 小角色造型 | 平常只顯示目前的角色，按「換一個」打開抽屜選擇，共八個 |
| 收音麥克風 | 預設跟著系統；系統預設是藍牙耳機時，會自動改用內建或 USB 麥克風。藍牙耳機不能選，拿來收音會讓耳機變成通話音質 |
| 快捷鍵 | 例如 `Control+Alt+Space` |
| 可讀資料夾 | 查資料時可以讀的資料夾，預設一個都沒有。**裡面的內容可能會送到 Claude**，只加你願意送出的資料夾。還不支援網路資料夾（`\\server\share`） |
| 筆記檔位置 | 筆記要寫到哪個檔案 |
| 所在地 | 例如「台北」。問天氣這類跟地點有關的事沒講地點時，就查這裡。**查資料時會隨問題送到 Claude** |
| 診斷模式 | 記下你說的每一句話，用來查問題。**測完請關閉，並刪除紀錄** |
| 回答引擎 | 目前只有 Claude Code |
| 重新走一次引導 | 想重新選麥克風或檢查環境時使用 |

## 隱私

- 喚醒前的聲音只留在記憶體，最近 3.5 秒不斷覆蓋，不存檔也不外送。
- 語音都在你的電腦上轉成文字。送到 Claude 的只有文字（問題，以及你填的所在地），錄音不會送出去。
- 問台灣縣市的天氣時，只把該縣市的座標送到 Open-Meteo，不送你說的話。
- 小小的紀錄檔只記事件（時間、延遲等），不記內容；只有開啟診斷模式才會記你說的話。
- Claude Code 會依它自己的規則，把對話文字（你問的問題和回答）存在電腦上的 `~/.claude/projects`（Windows 是 `%USERPROFILE%\.claude\projects`）。小小的對話在名稱結尾是 `xiaoxiao-workdir` 的資料夾裡，想清掉就刪這個資料夾；刪了不影響小小。
- 顧問模式的討論內容，小小自己只留在記憶體，結束就丟；只有你說「對」時，才把摘要寫進筆記檔。但跟一般問答一樣，Claude Code 本身會在本機留下對話文字（見上一條），顧問討論也包含在內。
- 小小只呼叫你自己登入的 Claude Code，不會自己登入，也不會讀取你的憑證。
- 就算資料夾加進可讀清單，`.env*`、`.ssh`、`*.pem`、`*.key`、`id_*` 和瀏覽器、系統金鑰的資料夾也一律不讀。
- 問 Claude 的問題會用到你自己的 Claude 額度；固定指令不會。

## 遇到問題

**喊了沒反應**

1. 看小角色是不是閉著眼睛。待命 2 分鐘沒互動就會休息，先點一下，聽到起床音後直接說問題。
2. 按右鍵看圖示選單的狀態，再對照上面的表。
3. 按快捷鍵試試。有反應就是喚醒詞沒聽到，靠近麥克風一點，或到設定換一支麥克風。
4. 都沒反應時，到設定按「重新走一次引導」，用音量條確認麥克風收得到聲音。
5. Windows 用遠端桌面連線時，小小可能抓不到實體麥克風。請回到電腦前操作，或結束遠端連線再試。

**小小一直顯示暫停中**

有其他程式佔著麥克風時就會這樣。關掉通話或會議軟體再看看，也檢查是不是讓它休息了。

**沒有聲音**

小小用系統內建語音說話。Mac 要有「美佳」，Windows 要有台灣國語語音，設定方法見[安裝說明](install.md)。

**快捷鍵沒反應**

可能被其他 app 佔用了，到設定換一組。如果電腦剛從睡眠醒來，而且叫它也沒反應，先結束小小再打開一次；目前這個情況不會有提示。

**看不到小角色**

可能被隱藏了，或正在通話中。從圖示選單按「顯示小角色」，或再打開一次小小。還沒走完引導時也不會出現。

**看不到小小的圖示**

Windows 先點系統匣的「^」。Mac 的選單列太擠時，圖示可能被藏起來，先收掉一些其他圖示。

**Windows 用遠端桌面連線時收不到音**

要在遠端桌面的設定裡開啟麥克風轉接。SSH 連線則收不到音。

**要回報問題時**

開啟診斷模式，重現一次，再把紀錄附上。**紀錄裡有你說過的話，傳出去之前先看過。** 紀錄位置：

- Mac：`~/Library/Logs/io.github.kerryhuang.xiaoxiao/events.jsonl`
- Windows：`%LOCALAPPDATA%\io.github.kerryhuang.xiaoxiao\logs\events.jsonl`

紀錄滿 5 MB 會改名成 `events.jsonl.1`，再開新檔，最多留這兩份。刪除紀錄時兩份都要刪。

# 小小

日常語音助理：說「嘿，小小」就出現，幫你查資料、回答問題、幫你做事。Mac 與 Windows 雙平台，喚醒、聽寫、說話都在本機完成。

> 狀態：試用中。Mac（Apple 晶片、macOS 13 以上）與 Windows（x64 的 Windows 10／11）。

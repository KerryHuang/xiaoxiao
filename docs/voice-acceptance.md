設計文件 §11 第 3 點：所有平台做完後一起實測。真人錄音不進 repo，這份只記結果。

## 驗收項目

| # | 項目 | 門檻 |
|---|---|---|
| V1 | 本人聲音直接對麥克風喊 20 次「嘿，小小」 | 命中至少 18 次 |
| V2 | 日常工作 30 分鐘以上不刻意叫小小 | 誤觸最多 1 次 |
| V3 | 問題講完到第一句開口（快答） | 不超過 3 秒 |
| V4 | 兩個平台各測一次 | Mac、Windows 都有紀錄 |

## 測試方式

- 測之前到設定頁打開「診斷模式」，紀錄在 `~/Library/Logs/io.github.kerryhuang.xiaoxiao/events.jsonl`（Windows 是 `%LOCALAPPDATA%\io.github.kerryhuang.xiaoxiao\logs\events.jsonl`）；
  `latency_ms` 可以看延遲。**測完關掉診斷模式並刪除紀錄**（診斷模式會記下你說的話）。
- V1：距離麥克風約 50 公分、平常音量，每次間隔 5 秒以上；聽到「我在」才算命中。
- V2：照常工作（打字、講電話、旁人交談），記下小小自己跳出來的次數與當時情境。
- V3：問「現在幾點」以外、需要 Claude 回答的簡短問題，例如「台北今天會下雨嗎」，看 events 的 `latency_ms`，或用碼表。

## Windows 真機清單

要在實體桌面測（遠端桌面沒有轉接麥克風時收不到音，SSH 也不行）。

- [ ] 真機測試程式全過：`real.exe --ignored --test-threads=1`（CI artifact `real-tests`）。
- [ ] 安裝程式能裝、SmartScreen 能略過；開始功能表有小小，系統匣看得到圖示（深色、淺色工作列都看得見）。
- [ ] 引導五步能走完，模型下載完成。
- [ ] 喊「嘿，小小，一公斤幾公克」聽得到回答；記下問題講完到開口的秒數（V3）。
- [ ] 全程沒有跳出黑色主控台視窗。
- [ ] 通話或瀏覽器麥克風測試時小小暫停，結束後恢復；鎖定螢幕時暫停。
- [ ] 藍牙耳機當預設輸入時，小小不選它收音。
- [ ] 快捷鍵、點系統匣圖示都能叫出小小；重開機後自動待命。
- [ ] 把測試資料夾加入可讀，問它 `.env` 的內容應該讀不到；一般檔案讀得到。
- [ ] 帳號資料夾含中文時模型載入得了（可把模型放到中文資料夾跑）。
- [ ] 解除安裝乾淨。
